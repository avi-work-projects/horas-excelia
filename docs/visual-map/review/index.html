También se revisan sus consumidores compartidos, las flechas y las incidencias anotadas. Un cambio sin efecto visible requiere comprobar y documentar su vigencia; no repetir las 150 capturas por sistema.

  3. Revisar visualmente, comprobar las flechas y marcar los hallazgos resueltos.
  4. Ejecutar map:check y map:verify; guardar las fuentes y láminas actualizadas con el cambio.
